# Step 8 — Where the sample comes from (bonzi.link)

## The download site
`bon4.zip` is the file offered at **https://bonzi.link/** — every download link on that page
points to `https://bonzi.link/bon4.zip`.

- The page imitates Bonzi Software's late-1990s landing page ("Copyright © 1995 - 2000 BONZI.COM
  Software", system requirements, feature list), but it is **not** Bonzi's: the `.link` domain is
  modern, the HTML is generated by the WYSIWYG tool "Web Page Maker" with absolute positioning (a
  re-creation, not a copy of the original HTML), and Bonzi Software closed around 2004.
- No author, no hashes, no source code and no mention of modifications on the page.
- Copy of the page as of 2026-10-09: `references/bonzi.link/index_20261009.html`.

So the installer inside the sample has been distributed unchanged since at least 2016 (and existed
by 2013); only the zip around it was rebuilt in 2025 (`Bon.zip` → `bon4.zip`, same contents).

## Who made the repack
Not stated anywhere. Traces in the files: installer branding "Copyright © 2012, Bonzi Software",
support link `http://bonzibuddy.tk`, the "Plan 9 Software" name in `BonziBUDDY_Killer.exe`, and the
Smart Install Maker 5.03 build. The VB Decompiler export on GitHub (NixButterPlay, 2022) was made from
this same repack installed on 64-bit Windows (report 05 / `references/README.md`).

## What this means for the analysis
The sample is the widely circulated "BonziBuddy432" fan repack, the same one found on bonzi.link,
the Internet Archive and GitHub. Reports 02, 05 and 06 show it contains Bonzi's own binaries and no
added malware; the risk is BonziBuddy's own behaviour (FINDINGS.md).
