# Form designs of BonziBUDDY v4.1

Designer sections (`Begin VB.Form ... End` + `Attribute` lines) of the 41 forms, user controls and
property pages, with their binary resources (`.frx`/`.ctx`) and `Project.vbp`. They describe every
control on every form (type, name, caption, position, properties) as stored in `BonziBDY_4.EXE`.

Source: VB Decompiler export in `references/NixButterPlay_BonziBuddy` (MIT licence,
Copyright (c) 2022 NixButterPlay). Its code sections (x86 disassembly) were dropped here; our own
per-object pseudocode is in the parent folder (`../<Object>.c`).

Provenance note: the `Object =` lines point to `C:\Program Files (x86)\BonziBuddy432\...`, i.e.
that export was made from this same BonziBuddy432 repack, installed on 64-bit Windows.
827 `Begin` blocks (forms + controls) in total.
