# Ghidra

- `project/` — Ghidra 12.1.2 project `Bonzi` with every analyzed binary. Functions are already
  renamed `Object::Procedure` (namespaces = VB6 forms/classes/modules), so it can be opened in the
  Ghidra GUI (`ghidraRun` → open `ghidra/project/Bonzi.gpr`) to browse the code.
- `input/` — copies of binaries with names Ghidra accepts (it rejects `'` in `Bonzi's ...`).
- `scripts/` — our Ghidra scripts (Java, run with `analyzeHeadless ... -postScript`):

| Script | Purpose |
|---|---|
| `DumpBonzi.java` | dumps strings (+ referencing functions), imports and functions → `reports/ghidra_dumps/` |
| `ExportSource.java` | renames functions from a map and writes one `.c` per VB6 object → `source/` |
| `RenameFunctions.java` | renames functions from a map without exporting |
| `Decompile.java` | decompiles given addresses |
| `DumpDisasm.java` | disassembly with string/function references resolved → `reports/evidence/` |
| `Callers.java` | lists the callers of given addresses |

- `logs/` — headless run logs (`export_<binary>.log`, regenerated by `scripts/vb6/generate_source.sh`).

Example:
```
/opt/ghidra/support/analyzeHeadless ghidra/project Bonzi -process BonziBDY_4.EXE -noanalysis -readOnly \
  -scriptPath ghidra/scripts -postScript DumpDisasm.java "$PWD/out.asm" 00678650
```
